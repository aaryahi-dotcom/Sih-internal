Prototype Built in a single day of development

This build exists to prove the core scoring pipeline end-to-end. It is not the production system described in the project brief, and nothing shown below reflects production-grade accuracy. Scope expands significantly across the phases that follow.

Live in this build

  • Scoring API (/api/v1/score)
  • Trained classifier + genuine SHAP output
  • Puppet-signature rule, Section 5.1
  • Scenario simulator, live feed & stats

Standing in for now

  • Small synthetic dataset, not IEEE-CIS
  • scikit-learn model in place of XGBoost
  • In-memory store in place of Redis
  • No PostgreSQL or Docker Compose yet

Coming soon

  • Transaction graph engine (Phase 2)
  • Analyst workbench & rule engine (Phase 3)
  • Fraud contagion heatmap (Phase 2)
  • Real IEEE-CIS-trained model
